## TikTok直播到底在检测什么

TikTok的风控逻辑简单说就是看IP像不像"真实住户"。行业里通常把可用的IP分成三个等级：机房IP最差，风控评分最低；原生IP（由当地运营商直接分配的商用或BGP网络IP）好一些；双ISP住宅IP（由本地家庭宽带运营商实际分配，且叠加两条ISP线路做冗余）目前被认为是TikTok场景里风险最低的一档。原因不复杂——住宅IP的注册信息、地理定位、历史行为轨迹都更贴近普通用户，机器学习模型不容易把它标记成"机房流量"。

如果你只是测试账号、偶尔登录看看效果，原生IP基本够用。但如果是要跑直播间、做多账号矩阵、或者账号已经出现过"数据异常""播放量骤降"的情况，双ISP住宅IP会是更保险的选择。这也是为什么丽萨主机把美国、日本、英国、韩国、越南这几个TikTok重点市场都单独做了"双ISP住宅IP"产品线，而不是笼统地卖一批机房VPS了事。
